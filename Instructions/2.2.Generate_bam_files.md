# Create a variation graph

## Map reads with bwa

To mitigate the effects of reference bias, museum reads should be mapped to a variation graph rather than a linear reference. Modern reads are first mapped to the reference using this script. Since bwa aln can take a long time to run, the initial mapping is first performed in parallel:

```bash
datapath=
reference=

mkdir -p $datapath/temp_bams/aln
parallel --memfree 400G --retries 10 \
'bwa aln -l 16500 -n 0.01 -o 2 -t 16 $datapath/reference/$reference {} \
> $datapath/temp_bams/aln/{= s:.*/::; s/\..*// =}.reads.sai 2> $datapath/temp_bams/aln/{= s:.*/::; s/\..*// =}.log' ::: $datapath/reads/museum_top_five/*.gz
```

From here, the script xxx can be run to process the mapped reads.
