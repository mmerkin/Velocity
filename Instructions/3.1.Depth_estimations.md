# Determine genome-wide depth 

Depth calculations can be used for quality control, filtering out samples with depths that are too low and for downsampling.

## Mosdepth

The tool mosdepth is used to estimate genome-wide depth 

The following command can be used to calculate the total sum of read lengths:
```bash
echo -e "Sample_name\tRead_pair\tTotal_bases" > read_totals.txt; for i in */reads*/*.gz; do name=$(echo $i | awk -F "_" '{print $2}' | sed 's/^[^-]*-//'); pair=$(echo $i | grep -o 'R[12]'); total=$(zcat $i | awk 'NR % 4 == 2 {sum += length($0)} END {print sum}'); echo -e "$name\t$pair\t$total" >> read_totals.txt; done
```

And this can calculate the average read length:
```bash
echo -e "Sample_name\tRead_pair\tAverage_length" > read_lengths.txt; for i in */reads*/*.gz; do name=$(echo $i | awk -F "_" '{print $2}' | sed 's/^[^-]*-//'); pair=$(echo $i | grep -o 'R[12]'); average=$(zcat $i | awk 'NR % 4 == 2 {total += length($0); count++} END {print total / count}'); echo -e "$name\t$pair\t$average" >> read_lengths.txt; done
```
