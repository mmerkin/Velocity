

The following command can be used to calculate the total sum of read lengths:
```bash
echo -e "Sample_name\tRead_air\tTotal_bases" > read_totals.txt; for i in */reads*/*.gz; do name=$(echo $i | awk -F "_" '{print $2}' | sed 's/^[^-]*-//'); pair=$(echo $i | grep -o 'R[12]'); total=$(zcat $i | awk 'NR % 4 == 2 {sum += length($0)} END {print sum}'); echo -e "$name\t$pair\t$total" >> read_totals.txt; done
```
