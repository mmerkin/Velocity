# Mitochondrial DNA

In contrast to nuclear DNA, mitochondrial genomes are haploid and non-recombining. This means they should be easier to reliably genotype at low coverage and they can be used to create phylogenetic trees.

In all species, the DToL produced a high quality reference mitochondrial genome with MitoHIFI. I did try to assemble the mitochondrial genomes de novo with tools such as NOVOPlasy and getOrganelle, but these would often fail to circularise, particularly with the museum samples. Additionally, de novo assemblies would often differ in highly repetitive regions. such as the AT-rich non-coding region (NCR). In particular, the three skipper species had exceptionally long NCRs in the reference that were not found in the de novo assemblies. Since it was more likely that the assemblers were cutting these regions short than the skippers independently evolving to have shorter NCRs in Britain, I decided to just use the single reference genomes.

## Preparation of reference genomes

A major issue with mitochondrial sequences is that they are circular, which means that the fasta sequences could have different starting points. As such, I decided to reorient each sequence to begin with the tRNA M gene, which would then place the NCR at the end of the sequence.

To do this, I used galaxy with mitos2 (genetic code 5 for invertebrate mitochondria) to identify all of the trnaM genes and then ran the script reorder_mtDNA.sh.

```bash
for i in reference/original/*.fa; do
species=$(basename $i _mtDNA.fa)
echo "Moving to: $species"
bash scripts/reorder_mtDNA.sh $i reference/trnaM/${species}_trnaM.fa > reference/reordered/${species}_MIQ.fa
rm reference/original/*.fa.*
done
```
Since the mitochondrial genome is circular but the fasta sequence is linear, there can be issues with the coverage tapering at the start and ends due to reads not mapping across the gap created during linearisation when bwa aln is used. As such, the tool CircularMapper is used to extend the genome by copying the first 500 bases to the end.

```bash
for i in reference/reordered/*; do
circulargenerator -e 500 -i $i -s "reordered_genome_forward"
done
```

## Mapping reads

As with the nuclear chromosomes, the modern samples should be mapped with bwa-mem2 and the museum with bwa aln.

Since the genomes are going to be mapped to the elongated genome, these should be indexed for use by both bwa aln. However, the modern samples and filtering will use the reordered genomes, so these need to be indexed separately and used to create a dictionary.

```bash
for i in *MIQ_500.fa; do
bwa index $i
done

for i in *MIQ.fa; do
j=$(basename $i .fa)
bwa-mem2 index $i
samtools faidx $i
picard CreateSequenceDictionary -R $i -O ${j}.dict
done
```
