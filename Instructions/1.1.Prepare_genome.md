# Prepare the reference genome

DToL have now released genome assemblies for all 17 species. Before mapping can begin, these must be downloaded, processed to remove unwanted contigs and indexed.

Genome files can be accessed from the ncbi genome page by clicking on the three dots under "Actions" and then "See more files on FTP". The link for ending in "genomic.fna.gz" should be downloaded and unzipped

Alternatively, softmasked genomes with numeric chromosome names can be accessed from the DToL website.
```bash
wget $LINK
gunzip $REF.fna.gz
mv $REF.fna $REF.fa
```
A list of all contigs can then be created using grep:
```bash
grep ">" $REF.fa | sed 's/>//'
```
If a W chromosome is present, it should then be removed. However, some species eg Adonis blue have many supernumeray W contigs so these can be removed at once by creating a txt file with all of their names
```bash
# One W
seqkit grep -v -p W $REF.fa > ${REF}_noW.fa
# Many Ws
seqkit grep -v -n -f W_scaffolds.txt $REF.fa > ${REF}_noW.fa
```

The genome containing autosomes, Z, mtDNA and unplaced contigs (everything except W) should then be indexed for mapping and initial processing. bwa index is used for bwa aln and bwa-mem2 index is used for bwa mem
```bash
samtools faidx $REF.fa
bwa index $REF.fa
bwa-mem2 index $REF.fa
picard CreateSequenceDictionary -R $REF.fa -O $REF.dict
```
Soft masked genomes can also be used to extract repeat regions for further filtering.

Firstly, the autosomes should be extracted to later restrict analysis to autosome regions with the bed file or angsd regions file.
```bash
cut -f1,2 $REF.fa.fai | awk -v OFS="\t" '{print $1, 0, $2}' > ${CODE}_autosomes.bed
nano ${CODE}_autosomes.bed # Use Ctrl+K to delete lines containing the Z chromsome and any unplaced scaffolds
cut -f1 ${CODE}_autosomes.bed > ${CODE}_autosomes.txt
awk 'BEGIN{OFS=""} !/^#/ && NF>=3 {print $1, ":", $2+1, "-", $3}' ${CODE}_autosomes.txt > ${CODE}_autosomes_regions.txt
```

Then, several files can be made to exclude repeats.

```bash
# hard masked reference genome for angsd
seqtk seq -x -n N $REF.fa > ${CODE}_hardmasked.fa 
#BED file with repeats locations
seqkit locate -G -P -r -p '[a-z]+' --bed "$REF.fa" |
cut -f1-3 |
bedtools sort -i - > "${CODE}_repeats.bed"
#BED file containing sites to keep on autosomes outside of repeats
bedtools subtract -a ${CODE}_autosomes.bed -b ${CODE}_repeats.bed > ${CODE}_autosomes_no_repeats.bed
```
