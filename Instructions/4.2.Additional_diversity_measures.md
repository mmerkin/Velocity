# ATLAS

ATLAS can be used to estimate heterozygosity based on the inferred substitution rate. Note that this requires a high memory usage and the "depth" option suggested in the documentation does not appear to work in rc11.

```bash
parallel -j 20 --memfree 400G --retries 10 \
atlas theta \
--regions *_autosomes.bed \
--genomeWide \
--RGInfo {.}_RGInfo.json \
--bam {} ::: */*/*.bam
```


# ANGSD

The site frequency spectrum (SFS) can be used in conjunction with the SAF (sample allele frequencies) to provide an alternate estimate for theta using ANGSD.

ANGSD can be installed easily from the [singularity container produced by James Santangelo](https://cloud.sylabs.io/library/james-s-santangelo).

```bash
~/apps/atlas_rc11/atlas/build/atlas saf --glf ${tag}_samples.txt --fasta ../../reference/*.fa;angsd realSFS saf.saf.idx > angsd_output.sfs
angsd realSFS saf2theta saf.saf.idx -sfs angsd_output.sfs -outname ${tag}_theta
angsd thetaStat do_stat ${tag}_theta.thetas.idx -win 10000 -step 1000 -outnames ${tag}_thetas_win10000
```
