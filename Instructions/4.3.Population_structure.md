# Quantify population structure

FS will be used. This needs to be set up first:

## Phasing vcf:

```bash
vcf=../G3modern_variants.filter3.vcf.gz
pop=G3modern
chroms=$(bcftools query -f '%CHROM\n' $vcf | sort -u)

for chr in $chroms; do
    bcftools view $vcf --regions $chr \
        -Oz -o ${pop}_chr_${chr}.vcf.gz
done

export PERL5LIB="/pub64/mattm/miniconda3/envs/cpan/lib/perl5/site_perl:$PERL5LIB" # Adds Switch.pm perl module to @INC

~/apps/fs_4.1.1/impute2chromopainter.pl G3modern_chr_1_phased.haps output_test

shapeit2 --input-vcf G3modern_chr_1.vcf.gz -O G3modern_chr_1_phased --thread 12 --window 0.5 --rho 0.0015

```
