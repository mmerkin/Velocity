NGSRelate	Meaning, conceptually
J1	All four alleles are IBD
J2	A's two alleles are IBD to each other, and B's two alleles are IBD to each other, but A and B are not IBD
J3	A's two alleles are IBD; one of B's alleles is IBD to A
J4	A's two alleles are IBD, but neither is IBD to B
J5	Mirror image of J3: B's two alleles are IBD; one of A's is IBD to B
J6	B's two alleles are IBD, but neither is IBD to A
J7	Both individuals have two alleles that are IBD across individuals — the classic IBD2 state
J8	One allele from A is IBD with one allele from B — classic IBD1
J9	None of the four alleles are IBD with each other — classic IBD0

# Sort by most inbred


```awk
gawk '
BEGIN { OFS="\t" }

NR == 1 { next }

{
    F[$3][++N[$3]] = $16
    F[$4][++N[$4]] = $17
}

END {
    print "Sample", "Median_F", "Mean_F", "Min_F", "Max_F", "N"

    for (s in F) {
        n = N[s]
        sum = 0

        for (i = 1; i <= n; i++) {
            x[i] = F[s][i]
            sum += x[i]
        }

        asort(x)

        if (n % 2)
            median = x[(n+1)/2]
        else
            median = (x[n/2] + x[n/2+1]) / 2

        mean = sum / n
        min = x[1]
        max = x[n]

        printf "%s\t%.6f\t%.6f\t%.6f\t%.6f\t%d\n", \
               s, median, mean, min, max, n

        delete x
    }
}' ${base}_relatedness.res | (read header; echo "$header"; sort -k2,2nr)
```
