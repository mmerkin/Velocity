# PMD

## PMDtools

The PMDtools [python script](https://github.com/pontussk/PMDtools/blob/master/pmdtools.0.60.py) can be used to assess the levels of PMD by showing the proportions of substitutions occurring at each position on the read. The only input is a bam file containing a CIGAR string and MD field. 
Since some tools e.g. ATLAS mergeOverlappingReads can remove MD fields, these may need to be re-added using [samtools](https://www.htslib.org/doc/samtools-calmd.html).

There are two modes:
- Deamination, which shows the substituion frequencies for just C
- Platypus, which shows all of the substitution frequencies, but splits C substitutions into those found in CpG sites.

### Deamination

```bash
parallel -j 10 'samtools view {} | python2 pmdtools.0.60.py -m 20 --requirebaseq 30 --minlength 50 --deamination > E3mus/platypus_output2/{/.}.PMD.txt' ::: /home/florat/velocity/aphantopus_hyperantus/museum_data/00_raw_reads_museum/*.sort.bam
```

### Platypus

```bash
parallel -j 10 'samtools view {} | python2 pmdtools.0.60.py -m 20 --requirebaseq 30 --minlength 50 --platypus > E3mus/platypus_output2/{/.}.PMD.txt' ::: /home/florat/velocity/aphantopus_hyperantus/museum_data/00_raw_reads_museum/*.sort.bam
```
n.b. PMDtools was written in python2, so this must be explicitly stated rather than using the default python3. Additionally, PMDtools does not recognise hard-clipping in the CIGAR string (H), so these reads will be skipped.

## Plot substitution profiles

The output of either mode can then be plotted in R directly or using one of the following scripts:
- Plot_single_deamination.R
- Plot_single_platypus.R
- [Plot_average_platypus.R](Velocity/scripts/2.Quality_control)
