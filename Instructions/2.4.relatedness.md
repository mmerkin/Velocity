|Unrelated | 0 | 1 | 0 | 0 | 0 | 0 |
|1st cousin | 3 | 0.75 | 0.25 | 0 | 0.125 | 0.0625 |

If there are two individuals, A and B, with alleles A A and B B at a particular locus, each Jacquard coefficient describes the relationship between these four alleles based on whether they are identical by descent (IBD). NGSRelate produces maximum likelihood estimates of these coefficients. J9, J8 and J7 are used to find the relationships between samples in the absence of inbreeding, whilst J1-J6 are used to identify inbreeding.

| Jacquard coefficient | Meaning |
| --- | --- |
|J9 | None of the four alleles are IBD with each other (IBD0) |
|J8 | One allele from A is IBD with one allele from B (IBD1) |
|J7 | Both alleles in each individual are IBD (IBD2) |
|J6 | Both alleles in B are IBD, but neither is IBD to A |
|J5 | Both alleles in B are IBD; one of A's alleles is IBD to B |
|J4 | Both alleles in A are IBD, but neither is IBD to B |
|J3 | Both alleles in A are IBD; one of B's alleles is IBD to A |
|J2 | Both alleles in A are IBD to each other, and both alleles in B are IBD to each other, but A and B are not IBD |
|J1 | All four alleles are IBD |

# Sort by most inbred


```awk
gawk '
BEGIN { OFS="\t" }

NR == 1 { next }

{
    F[$3][++N[$3]] = $16
    F[$4][++N[$4]] = $17
}

END {
    print "Sample", "Median_F", "Mean_F", "Min_F", "Max_F", "N"

    for (s in F) {
        n = N[s]
        sum = 0

        for (i = 1; i <= n; i++) {
            x[i] = F[s][i]
            sum += x[i]
        }

        asort(x)

        if (n % 2)
            median = x[(n+1)/2]
        else
            median = (x[n/2] + x[n/2+1]) / 2

        mean = sum / n
        min = x[1]
        max = x[n]

        printf "%s\t%.6f\t%.6f\t%.6f\t%.6f\t%d\n", \
               s, median, mean, min, max, n

        delete x
    }
}' ${base}_relatedness.res | (read header; echo "$header"; sort -k2,2nr)
```
