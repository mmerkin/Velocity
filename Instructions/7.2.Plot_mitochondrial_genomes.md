# Circular genome viewer

Before starting to obtain my mtDNA sequences, I decided to view their structure.

First, I ran mitos to identify genomic features and produced a seq file.

Then, I used the [genbank submission portal](https://submit.ncbi.nlm.nih.gov/genbank/template/submission/) to create a sbt file.

Afterwards, I could create a genbank file in the command line:

```bash
conda activate mtDNA
table2asn -i Aphantopus_hyperantus_MIQ.fsa -t Aphantopus_hyperantus_template.sbt -f Aphantopus_hyperantus_MIQ.tbl
asn2gb -i Aphantopus_hyperantus_MIQ.sqn -o Aphantopus_hyperantus_MIQ.gb
```

If there were any errors, I had to rename some genes eg trnaS2 to trnaS.
