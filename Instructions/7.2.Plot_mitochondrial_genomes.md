# Circular genome viewer

Before starting to obtain my mtDNA sequences, I decided to view their structure.

First, I ran mitos to identify genomic features and produced a seq file.

Then, I used the [genbank submission portal](https://submit.ncbi.nlm.nih.gov/genbank/template/submission/) to create a sbt file.

Afterwards, I could create a genbank file in the command line:

```bash
genus_species=





genus=$(echo "$genus_species" | cut -d'_' -f1)
species=$(echo "$genus_species" | cut -d'_' -f2)
mkdir $genus_species
cd $genus_species
nano ${genus_species}_annotation.tbl

# Paste mitos seq file


ln -s ~/Velocity/mitochondria/reference/reordered/${genus_species}_MIQ.fa ${genus_species}_mtDNA.fsa
cat ${genus_species}_annotation.tbl | sed -E 's/\([^)]*\)//g; s/\b(LEU|SER)[12]\b/\1/g' > ${genus_species}_mtDNA.tbl
table2asn -i ${genus_species}_mtDNA.fsa -t ../genbank_template.sbt -f ${genus_species}_mtDNA.tbl
asn2gb -i ${genus_species}_mtDNA.sqn -o ${genus_species}_mtDNA.gb
../update_genbank.awk $genus $species ${genus_species}_mtDNA.gb > ${genus_species}_mtDNA_updated.gb
```


Then, you can view this with a browser, either online or with chloroplot in R:

```R
library(chloroplot)
table <- PlotTab("Aglais_urticae_mtDNA_updated.gb", T)
PlotMitGenome(table, organelle_type = F)
```
