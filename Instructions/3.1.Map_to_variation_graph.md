# Create a variation graph

To mitigate the effects of reference bias, museum reads should be mapped to a variation graph rather than a linear reference, which is created from the vcf of the modern samples. The first round of sites filters are applied to reduce the complexity of the graph.

## Variation graph

The variation graph can now be constructed with vg. The graph is also indexed and pruned to further reduce complexity and the run time of mapping.

```bash
vg construct -r $REF -v ${base}_variants.filter.sites.vcf.gz -p > ${base}.vg
vg index -t ${threads} -p -x ${base}.xg ${base}.vg
vg prune -t ${threads} -p -r ${base}.vg > ${base}.prune
vg index -t ${threads} -p -g ${base}.gcsa ${base}.prune
```

## Mapping to variation graph

For the sake of consistency, the modern samples are also mapped to the variation graph.

The following steps are perfomed:
- vg map with options -w 300 -k 15 as used by Zach Nolen. -w specifies that band-width and -k is the minimum length (in bases) for a seed hit to be considered valid.
- Adds readgroup and md tags
- Sorts the bam file
- Removes unmapped and secondary reads
- Removes duplicate reads
- clips read overlaps
- Realigns reads around indels

The museum samples are handled similarly, except 1) clipping is not performed as reads were already merged 2) dedup is used for duplicate removal instead of samtools markdup -r

## Reference bias (coverage)

Reads carrying alternate alleles have more mismatches with the reference genome than those carrying reference alleles, resulting in a lower mapping quality. This may result in variant callers either missing alternate alleles or falsely calling heterozygous sites as being homozygous reference, biasing estimates of heterozygosity-based statistics. Reference bias will vary between populations based on the distance to reference genome and based on the size of the read, since short fragmented reads with many alternate alleles will have a very low mapping quality. [(Günther and Nettelblad, 2019)](https://doi.org/10.1371/journal.pgen.1008302)
