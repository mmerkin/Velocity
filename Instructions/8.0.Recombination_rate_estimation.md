Firstly, smc++ is used to create a demography file:

```bash
mkdir out
./smc++ vcf2smc B1modc_renamed.vcf.gz out/chr5.smc.gz 5 POP1:CMin-20-2017-01,CMin-20-2017-02,CMin-20-2017-03,CMin-20-2017-04,CMin-20-2017-05,CMin-20-2017-06,CMin-20-2017-07,CMin-20-2017-08,CMin-20-2017-09,CMin-20-2017-10,CMin-20-2017-11,CMin-20-2017-12,CMin-20-2017-13,CMin-20-2017-14,CMin-20-2017-15,CMin-20-2017-16,CMin-20-2017-17,CMin-20-2017-18,CMin-20-2017-19,CMin-20-2017-20,CMin-20-2017-21,CMin-20-2017-22,CMin-20-2017-23,CMin-20-2017-24,CMin-20-2017-25,CMin-20-2017-26,CMin-20-2017-27,CMin-20-2017-28,CMin-20-2017-29,CMin-20-2017-30,CMin-20-2017-31,CMin-20-2017-32,CMin-20-2017-33,CMin-20-2017-34,CMin-20-2017-35,CMin-20-2017-36,CMin-20-2017-37,CMin-20-2017-38,CMin-20-2017-39,CMin-20-2017-40,CMin-20-2017-41 --length 23591803
mkdir analysis
./smc++ estimate -o analysis/ 2.9e-9 out/chr*.smc.gz
./smc++ plot --csv plot.pdf analysis/model.final.json
```

Afterwards, pyrho can be used:

Note that individual vcfs need to be created per chromosome.

```bash
pyrho make_table -n 20 -N 25 --mu 1.25e-8 --logfile . --outfile ACB_n_20_N_40_lookuptable.hdf --approx --smcpp_file ACB_pop_sizes.csv --decimate_rel_tol 0.1
pyrho optimize --tablefile B1modc_n_82_N_100_lookuptable.hdf --vcffile B1modc_chr1.vcf --outfile B1modc.rmap --logfile . --ploidy 2
```
