
Bcftools is used to call the variants

```bash
bcftools mpileup -b ${base}_bamlist.txt -f $REF -a "FORMAT/QS,FORMAT/AD,FORMAT/DP,INFO/AD" -B | bcftools call -m --threads $threads --ploidy 2 -a GQ,GP -v -Oz -o ${base}_variants.raw.vcf.gz
```

A basic set of filters is first used to reduce the file size. Filters remove 1) snps within 5 bases of indels 2) SNPs with a quality below 30 3) SNPs with at least 30% missingness across all samples 4) Multiallelic variants 5) Indels

```bash
bcftools filter -g 5 -i'QUAL >= 30 && F_MISSING<=0.7' -Ou ${base}_variants.raw.vcf.gz | \
bcftools view -m2 -M2 -v snps -Oz > ${base}_variants.filter.sites.vcf.gz
```

Since we are only interested in autosomes for all analyses that use the vcf, a bed file is used to retain only these regions. Also, repetitive regions will also be removed during this step

```bash
bcftools view -R $BED ${base}_variants.filter.sites.vcf.gz -Oz -o ${base}_variants.filter.repeats.vcf.gz
```
