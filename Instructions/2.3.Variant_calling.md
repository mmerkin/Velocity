
Bcftools is used to call the variants

### Variant calling

```bash
bcftools mpileup -b ${base}_bamlist.txt \
-f $REF -a "FORMAT/QS,FORMAT/AD,FORMAT/DP,INFO/AD" \
-B | bcftools call -m --threads $threads --ploidy 2 \
-a GQ,GP -v -Oz -o ${base}_variants.raw.vcf.gz
```

## Basic sites filters

A basic set of filters is first used to reduce the file size. Filters remove 1) snps within 5 bases of indels 2) SNPs with a quality below 30 3) SNPs with at least 30% missingness across all samples 4) Multiallelic variants 5) Indels

```bash
bcftools filter -g 5 -i'QUAL >= 30 && F_MISSING<=0.7' -Ou ${base}_variants.raw.vcf.gz | \
bcftools view -m2 -M2 -v snps -Oz > ${base}_variants.filter.sites.vcf.gz
```

## Regions filter

Since we are only interested in autosomes for all analyses that use the vcf, a bed file is used to retain only these regions. Also, repetitive regions will also be removed during this step

```bash
bcftools view -R $BED ${base}_variants.filter.sites.vcf.gz -Oz -o ${base}_variants.filter.repeats.vcf.gz
```

## Site depth filter

The repeat annotation is not perfect and there may still be some regions with artificially high depths, so a a depth filter is applied. This script removes variants with a total depth in the top and bottom 1% of the depth distribution. A summary file is also produced showing the depth distribution, so you can rerun the command with new thresholds if it turns out they were not suitable.

```bash
bash ~/Velocity/scripts/filter_vcf_depths.sh ${base}_variants.filter.repeats.vcf.gz ${base}_variants.filter.depth.vcf.gz 1 99
```

## Optional filters

There are now two optional filters that can be used when highly confident calls are required, but they throw away a lot of extra data at low coverage.

### Genotype masking

Genotypes can be masked (set to missing) if they do not meet a GQ or DP threshold.

For high depth samples, min_dp of 3 and min_gq of 20 are both suitable thresholds. At a lower depth, you may wish to first inspect the depth and quality distributions:

```bash
bash ~/Velocity/scripts/vcf_filters/summarise_vcf_DPGT.sh ${base}_variants.filter.depth.vcf.gz ${base}_variants.filter.depth.quality_summary.txt
```

The thresholds can then be used to mask individual genotypes.

```bash
bcftools filter \
-S . \
-e "FMT/DP < $min_dp || FMT/GQ < $min_gq" \
${base}_variants.filter.depth.vcf.gz \
-Oz -o ${base}_variants.filter.masked.vcf.gz
```

### Sample filter

Individuals can be removed if they either have exceptionally high missingness or they are close relatives with another sample.

This step may need to be revisited after relatives are identified (tab 2.4), but individual missingness can be identified from a stats file.

```bash
bcftools stats -s - ${base}_variants.filter.depth.vcf.gz > ${base}_variants.filter.depth.stats.txt # Replace "depth" with "masked" if masked filters were applied

awk '
$1 == "SN" && $3 == "number" && $4 == "of" && $5 == "SNPs:" {
    total_sites = $6
}

$1 == "PSC" {
    sample = $3
    mean_dp = $10
    missing = $14 / total_sites

    printf "%s\t%.1f\t%.6f\n", sample, mean_dp, missing
}
' ${base}_variants.filter.depth.stats.txt > ${base}_variants.filter.depth.sample_missingness.txt
cat ${base}_variants.filter.depth.sample_missingness.txt | sort -nrk 3
```

A txt file should be created containing the list of samples to be removed, which can then be filtered out with bcftools.

```bash
bcftools view \
-S ^discard_samples.txt \ # Ensure the "^" is used, otherwise only those samples will be kept
${base}_variants.filter.depth.vcf.gz \
-Oz -o ${base}_variants.filter.samples.vcf.gz
```

## Site missingness filter

This should be one of the final filters used to exclude variants with high missingness across all samples. If population filters are being applied (see below), this should be performed on each population separately.

First, a summary file can be created to show the effect of each missingness threshold

```bash
bash ~/Velocity/scripts/vcf_filters/summarise_vcf_missingness.sh ${base}_variants.filter.depth.vcf.gz > ${base}_variants.filter.depth.missingness_summary.txt
```

Once a threshold has been chosen, the last thing to do is apply the missingness filter.

```bash
bcftools view \
-i 'F_MISSING <= 0.05' \
${base}_variants.filter.depth.vcf.gz \
-Oz -o ${base}_variants.filter.missingness.vcf.gz
```


## Further optional filters

There are three final additional filters that could be applied

### Population filters

When I return to the GONE analysis, I may end up using population-specific filters e.g. HWE. These should be avoided on data from the whole population due to the Wahlund effect. 

### MAF

MAC or MAF can be used to filter out rare variants under the assumption that they are sequencing errors

### LD

Some analyses e.g. PCA may require LD pruning
